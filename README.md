# Satoshi Miner

Browser-Spiel (Deutsch), in dem du Satoshis „minest“.

## Spielen

Öffne [GitHub Pages](https://bullfish77.github.io/satoshi-miner/) oder lokal `index.html` im Browser.

## Features

- Tippen/Halten zum Minen mit echtem SHA-256 (`crypto.subtle`)
- Block-Belohnungen in Sats, Schwierigkeit, Halvings
- Upgrades (GPU, ASIC, Pool, Kühlung, …), passive Hashrate
- Zufällige Events, Erfolge, Speichern im Browser (`localStorage`)
- Werbe-Stubs und Lightning-Auszahlungs-Hook (noch deaktiviert)

## Hinweis

Spiel-Sats sind keine echten Bitcoins. Die Sektion „Echte Sats“ ist vorbereitet für werbefinanzierte Lightning-Auszahlungen, aber noch nicht aktiv.
